# Security Policy

## Supported Versions

Currently, only the latest release of Azokle Notes is supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

We take the security of Azokle Notes seriously. If you believe you have found a security vulnerability in Azokle Notes, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to us via email at **support@azokle.com**.

You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your original message.

Please include the following information in your report:

* Description of the vulnerability.
* Steps to reproduce the vulnerability.
* Potential impact.
* Any related code or logs you have.

We will evaluate the vulnerability and, if confirmed, work on a fix. Once the fix is ready, we will release an update and acknowledge your contribution (if you desire).

Thank you for helping us keep Azokle Notes safe!
